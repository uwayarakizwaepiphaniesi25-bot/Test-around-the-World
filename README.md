Taste Around The World 

About the Project

Taste Around The World is an international culinary website designed to introduce visitors to different foods, countries, and food cultures around the world.

Website Features

- Home: Introduction to the website and featured dishes.
- Menu: Explore 12 international dishes from four regions.
- Countries: Discover food and cultures from different countries.
- Gallery: View food pictures and filter them by region.
- Contact: Send questions, suggestions, and feedback.

Technologies Used

- HTML
- CSS
- JavaScript
- Formspree (Contact Form)

Purpose

The purpose of this project is to help people explore international food and learn about different cultures through food.
